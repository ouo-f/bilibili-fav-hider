# b站收藏夹助手

一个极简的 Chrome / Edge 浏览器扩展（MV3），在你自己的浏览器里**本地隐藏B站网页版中指定的收藏夹**，防止身边的人（借电脑、投屏、远程演示时）看到。公开收藏夹和已设置为B站"私密收藏夹"的都适用。

**纯本地显示过滤：零网络请求、不碰 cookie、不调用B站接口 → 服务器感知不到它的存在，无风控风险。**

> **声明**：本项目为非官方的个人开源作品，与哔哩哔哩（bilibili）官方无任何关联；仅供个人学习交流使用。"b站"等名称仅为描述性指代。

## 安装（一次性，约1分钟）

1. 点击仓库右上角绿色 **Code** 按钮 → **Download ZIP**，解压到任意位置（或 `git clone` 本仓库）；
2. 打开 Edge，地址栏输入 `edge://extensions` 回车（Chrome 用 `chrome://extensions`）；
3. 打开左下角（Edge 为左侧栏底部）的 **"开发人员模式"/"开发模式"** 开关；
4. 点击 **"加载解压缩的扩展"**，选择解压出来的文件夹；
5. 工具栏出现扩展图标即安装成功。之后B站页面上立即生效，无需其他设置。

> 卸载：扩展管理页移除即可，浏览器登记与配置数据随之清除，不留任何痕迹。

## 配置

点击浏览器工具栏上的扩展图标，在文本框中**每行一条**填写要隐藏的收藏夹：

```
某收藏夹的关键字  ← 文件夹名关键字（主规则，推荐）
完整文件夹名     ← 也可以是完整名称
123456         ← 纯数字行会被当作 fid（可选增强）
```

保存后**刷新B站页面**生效（配置存在浏览器账号里，换设备登录同一浏览器账号也会同步）。

### 填名称还是填 fid？

| 规则 | 侧栏条目 | 视频页收藏弹窗 | 直链 ?fid=xxx 防护 | 空间页收藏夹卡片 |
|---|---|---|---|---|
| 名称关键字 | ✅ | ✅ | ✅（按内容区标题判断） | ✅（按文本） |
| fid（纯数字） | ❌（新版侧栏不带 fid） | ❌ | ✅（秒级重定向回列表） | ✅ |

**建议：名称关键字必填**（覆盖面最全），fid 可选加填（直链防护更精准、收藏夹改名后仍有效）。

- **名称关键字**：收藏夹的完整名字或其中一段独特文字。注意是"包含匹配"——填 `学习` 会同时隐藏 `学习资料`；
- **fid 获取**：打开那个收藏夹，地址栏形如 `space.bilibili.com/你的UID/favlist?fid=123456`，`fid=` 后的数字就是。

## 隐藏了哪些位置？

1. **收藏夹管理页**（`space.bilibili.com/你的UID/favlist`）左侧栏中的条目；若某分组下全部条目都被隐藏，连分组标题（如"私密收藏"）一起隐藏；
2. **直链访问**被隐藏收藏夹（地址栏输入 `?fid=xxx`）→ 自动弹回收藏列表；收藏夹内容区标题命中名称规则时也会隐藏整列内容；
3. **视频页"收藏"弹窗**里对应的文件夹行（弹窗内条目不带 fid，按名称匹配）；
4. **空间页的收藏夹卡片**等带 fid 的链接；
5. **顶栏"收藏"悬浮面板**（首页/视频页/动态页等右上角）：左列中命中规则的收藏夹条目被精准隐藏；若被隐藏的收藏夹正处于选中状态（右侧预览区展示它的视频），预览区也会一并隐藏，切换到其他收藏夹后自动恢复。条目隐藏采用不改变布局的方式（隐形但留占位），以兼容B站面板的展开动画。另提供"兜底：隐藏整个顶栏面板"开关（默认关闭）。

## 工作原理与性能

- content script 注入B站页面，用 `MutationObserver` 监听 DOM（适配SPA动态渲染），命中的元素打上隐藏样式（普通位置用 `display:none`；顶栏面板内用不改变布局的 `visibility:hidden`，以兼容面板展开动画）；
- 扫描做了防抖合并（200ms），每次只是几个轻量的 `querySelectorAll`，实测最繁忙的视频页上 CPU 占用约 0.1% 单核；
- **无 background**（MV3 service worker 不存在），浏览器不为此扩展保留任何常驻进程，任务管理器里看不到它；
- 权限只有 `storage` / `scripting` / `activeTab` + B站全站子域名（`*.bilibili.com`，覆盖主站/空间/动态/搜索/账号中心/消息中心/直播等全部页面）的注入声明。

### 已实测校准的 DOM 结构（2026-09）

| 元素 | 选择器/特征 |
|---|---|
| 侧栏条目 | `.fav-sidebar-item`（`title` 属性=完整文件夹名，无 fid） |
| 侧栏分组 | `.fav-collapse .vui_collapse_item`（标题如"TA创建的收藏夹"） |
| 内容区标题 | `.favlist-info-detail__title` |
| 内容区整列 | `.favlist-main` |
| 收藏夹链接（卡片/旧版） | `a` 且 **pathname 含 `/favlist`**（注意 `spm_id_from=...favlist...` 追踪参数会误伤，已排除） |
| 收藏弹窗 | 弹层容器含"新建收藏夹/创建收藏夹"文案（比类名抗改版） |
| 顶栏悬浮面板 | `.favorite-panel-popover__nav .tab-item`（`.tab-item__title`=名称）+ `.favorite-panel-popover__content`（预览区） |

B站改版导致失效时，改 `content.js` 顶部"常量区"的选择器即可，逻辑不用动。

## 安全边界（必读）

- 本扩展是**本地 UI 隐藏**：防的是"身边的人随手一看"。懂浏览器的人按 F12、直接改 URL 理论上仍能发现（直链已被重定向，但属于软防护）；
- 它只影响**你这台电脑的浏览器**。要防"别人在自己设备上访问你主页"，请用B站自带功能：收藏夹设为**私密**（编辑收藏夹里勾选）或空间设置里整体隐藏收藏——两者互补，建议都做；
- 密码门（点击🔒输密码才显示）是天然的下一步迭代，当前版本未包含。

## 调试

- 扩展弹窗勾选"调试日志"后，B站页面控制台（F12）会输出 `[收藏夹隐藏]` 前缀的命中日志；
- 页面控制台里把 **Context 环境下拉从 `top` 切换到本扩展**后，可用钩子手动切换规则测试：`__bvhTest.apply({rules:['关键字'], debug:true})`；`__bvhTest.apply({rules:[]})` 还原。钩子位于扩展的隔离环境，网页脚本接触不到它。

## 从源码构建

在仓库根目录用 PowerShell 执行 `.\pack.ps1`，生成 `bilibili-fav-hider-v<版本号>.zip`（manifest.json 位于压缩包根目录），可直接用于 Edge / Chrome 商店上传。
